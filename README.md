# Multi-Tenant Project Management SaaS APP

> PMS is a Multi-Tenant Project Management Saas. The App offers **Data Isolation, Multi-Tenancy, Security and Collaboration** features.

> This project is a **production ready application**.

 **The Project is built using the technologies given below.**
## Tech Stack : 
* **Java (21)**
* **Spring Boot (4.1)**
* **Postgres (17)**
